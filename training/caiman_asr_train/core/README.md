# Inference only API

The files in this folder are expected to conform to a minimal dependency set.
This is to allow for external tooling to import and use them for testing.

For how the YAML config, model config, training checkpoint, and hardware
checkpoint relate to one another and the functions that convert between them,
see the "Config & checkpoint hierarchy" page in the docs
(`docs/src/training/config_and_checkpoints.md`).
